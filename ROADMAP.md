# Roadmap
The independent reference-software work is evaluated against the frozen gates. Deployment work requires qualified external resources: radiometric thermal and active depth devices, authorized coarse radar, consented representative human/fire data, reviewed detector models and independent safety/privacy assessors. Native mobile bindings need device/SDK capability checks and real-device evidence. Each adapter must pass darkness, calibration, dropout, spoofing and output minimization tests before qualification.

No identity, re-identification, pursuit, targeting, precise behind-wall person reconstruction or weapons roadmap exists. Do not expand features to obscure missing evidence. No production or release date is promised.
