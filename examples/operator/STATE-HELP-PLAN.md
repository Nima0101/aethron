# State-guidance inventory slice

Derive the current component's locale/state unions and localized titles/bodies
from its TypeScript AST. Reject missing/extra state guidance, missing locales,
duplicates, malformed syntax and executable expressions. Bind the generated
STATE-HELP.json to exact source bytes, standalone module bytes and clean/dirty
Git provenance. Check all topics against executed bundled UI states in both
languages, including actual contextual details entry points, without network.

Eleven missing-module checks precede implementation; retain those results and
negative source mutations. Integrate generation into the browser build with stale
artifact invalidation and byte-identical recovery. Use a closed JSON ADR and
source-bound evidence. No sub-agents or heavy qualification.

This is the state portion of the required help inventory. It explicitly leaves
action-specific guidance, routes/roles, search/onboarding/manuals, signed release
and installed browser/customer acceptance unfinished. Its presence cannot pass
P19.7. The current component has no account/admin routes to invent documentation
for. Technology choice and official parser alternatives: state-help-adr.json.
