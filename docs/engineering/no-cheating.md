# No-cheating rules v1
Never weaken/delete tests or shift thresholds to get green; hide skipped/flaky checks, false positives or false negatives; overlap train/test and claim generalization; fabricate sensor feeds, live benchmarks, videos or performance; claim unexercised hardware; label simulation live; hide failures behind smoothing; convert UNKNOWN to SAFE; silently drop uncertainty; claim sensor accuracy without reproducible data/protocol; claim production readiness from a demo; publish fake live feeds or unclear-provenance models/data; add prohibited capabilities. Preserve negative results and regressions. A corrected test requires an explicit spec error, retained counterexample and stronger replacement. No fake adoption, fabricated review independence or invented compliance. Record errors without copying private payloads.
