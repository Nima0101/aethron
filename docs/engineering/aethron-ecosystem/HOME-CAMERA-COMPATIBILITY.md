# Home/smart-camera and fixed hub recipe — SPEC ONLY

Normal installation is an authorized package on capable camera hardware or a permanently running NVR/NAS/edge hub with local camera feeds. A cloud-only camera with no authorized local stream is not supported by inference; documented RTSP/ONVIF/vendor local export or an independently selected camera is required. Internal sensor wiring, PoE and local LAN are part of the installed system; WAN and a logged-in phone are not.

1. Inventory exact camera/hub OS/CPU/firmware, stream codec/resolution/clock, SDK terms and power/PoE budget. Confirm persistent local API availability without vendor-cloud login/heartbeat. Encrypted proprietary access must not be bypassed.
2. Choose direct on-device package if the vendor permits its resource/permission/lifecycle use; otherwise install the signed edge image/service on a fixed local hub with appropriate cooling/storage/endurance. A NAS app or container must have real auto-start under its platform manager, not an open browser tab.
3. Place cameras only in authorized areas with necessary household/visitor/workplace privacy notices and lawful basis; minimize FOV and disable recording/upload by default. Person tracks remain ephemeral; no cross-camera re-identification or durable household history.
4. Commission local credentials, camera allowlist, calibration and offline model/plugin manifests. Provide local status indicator/UI/API, owner authentication, update/recovery guide and default network segmentation. WAN access is optional and disabled for normal inference.
5. Close setup apps, unplug programming laptop, turn off phone Bluetooth/Wi-Fi, disconnect WAN and reboot camera/hub. Leave local PoE/LAN sensors connected. Require local stream acquisition, on-device inference, UNKNOWN on sensor loss and independently available status with zero viewers.
6. Exercise corrupted model/update, disk-full, source reboot, Wi-Fi/LAN outage, clock reset and thermal/CPU pressure. Network camera timestamps with unbounded encode/transit delay cannot become fresh v3 evidence. Delayed observation must be labeled separately.
7. For true zero-visible sensing, verify actual active NIR/LWIR/radar/depth capability/optics and appropriate eye-safety/installation evidence. An ordinary indoor RGB camera or generated night filter cannot close the gate.

Operator guide: power the fixed unit, interpret boot/observation/fault indicators, use optional local diagnostics if needed, and contact the installer/reprovision when a latched fault persists. No day-to-day terminal/phone/monitor is needed for the pipeline to run. Never market security threat scoring or emergency-response guarantees. A01–A09 in [APPLIANCE-RUNTIME](APPLIANCE-RUNTIME.md) are required; exact SKU and domain evidence remains Level C/D work.
