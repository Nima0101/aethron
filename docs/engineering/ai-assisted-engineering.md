# Public AI-assisted engineering workflow v1
A human owner sets purpose and immutable limits. One AI implementation owner reads prior quality references, freezes explicit invariants and tests, researches primary sources, records architecture decisions, implements, runs adversarial checks, corrects defects, and records evidence. No sub-agents; no independent human audit claimed. Predictions become testable hypotheses. Separate oracle code challenges fusion semantics but shares authorship. Public documents contain decisions, sources, measured results and limits, never hidden chain-of-thought or private conversations. Gate states follow executable evidence; visual design follows functioning behavior.
