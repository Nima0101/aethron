# Model and data provenance policy v1
Every distributed model and dataset needs source, license, author/origin, intended use, forbidden use, immutable SHA-256, format version, reproducible generation/loading, limitations and card. No scraped personal data, unclear-license weights, unreviewed downloads or pickle/executable deserialization. Reject artifact tampering and unknown model parameters. Deterministic rule models may be integrated honestly as rule models, never portrayed as learned perception. Synthetic fixtures test software semantics only. Human presence accuracy requires legally obtained, consented, representative held-out labeled data and error breakdowns; no synthetic result substitutes for this.
Freeze evaluation protocol before results; keep train/test generation disjoint and disclose no training when appropriate. Publish false positives and negatives, missingness, subgroup/environment limits where ethically measurable, and uncertainty calibration. No accuracy, field performance or live readiness claim from tiny synthetic tests. If appropriate weights/data or devices are unavailable, integrate only reviewed safe artifacts and record the missing capability evidence as a production blocker.
