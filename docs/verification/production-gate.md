# Production-readiness gate v1
S01–S15 and H01–H04 must pass for the exact candidate and each explicitly named supported deployment. All claims need timestamped evidence, versions, commands and limitations. There is no generic multi-platform production-ready label. Unsupported hardware is blocked, never simulated into support. Controller authority requires independent safety engineering. No certification or operational rescue suitability is implied by this gate. Zero unresolved critical/high software defects, zero critical TODO/FIXME, reproducible models/data, empirical calibration and negative controls are mandatory. Failures reopen dependent gates. Blocked H rows do not excuse unfinished independent S work.
