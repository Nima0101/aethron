All S rows required for a local software candidate and publication. H rows required for production; no silent N/A.

|---|---|

| S04 | Timestamp skew, replay/future/stale frames, dropped frames, stale calibration, clock mismatch, unsupported combinations pass |
| S05 | Darkness, saturation, occlusion, radar noise/multipath, spoof/outliers, disagreement, single-sensor degradation withdraw claims |

| S08 | Every action restricted to declared contract; uncertainty triggers fail-safe; expiry tested; no direct actuation |
| S09 | At least 2000 deterministic generated property cases plus a separately expressed fusion oracle; parser fuzz for at least 60 seconds, no unresolved crashes |
| S10 | Synthetic labeled evaluation includes human-cue false positive/negative reporting and thermal false positive controls; no real-world accuracy inference |
| S11 | Static/security analysis, dependency/license inventory and public leak scan; no unresolved high/critical software finding |
| S12 | Fresh git clone: README quickstart, full verification, library consumer and adapter examples pass |
| S13 | Two byte-identical release builds, SHA-256, SBOM, source manifest/provenance, install and consumer check |
| S14 | Original vector identity/architecture; actual command capture and reproducible synthetic visual/demo covering all seven flagship cases |
| S15 | OSS docs, license/notices, contribution/security/conduct/roadmap, issue/PR templates, CI/security/release workflows; zero critical unfinished source |
| H01 | Hosted CI/security checks on every claimed platform and anonymous clone verification |
| H02 | Each live sensor/device/platform: exact hardware/firmware, physical scenes/calibration, error/latency/power/missingness results and hardware-in-loop controller evidence |
| H03 | Licensed/consented representative held-out physical human/thermal data; FP/FN/uncertainty calibration; independent privacy and safety review |
| H04 | Tagged source, hosted signed provenance/attestation, downloaded release verification |

No performance threshold or field accuracy is claimed before domain-specific protocols and independent review. Local software semantics cannot close H02 or H03.
