# OEM embedded operator guide — access dependent

Use only an OEM-authorized package on a documented supported compute/camera interface. Installation, trusted signing and startup follow that OEM's platform manager. Ordinary users power on the host and inspect its local status; no laptop, user USB provisioning host, phone or license-server session sustains operation.

A camera permission or platform fault means UNKNOWN. Report it through the approved service process; never bypass camera DRM, security gateways, calibration or ADAS safety wiring. AETHRON's outputs are observations and recommendations, not certified driving functions or actuator commands.

The generic Linux software recipe has a boot-test lane. No proprietary OEM environment or exact vehicle camera API has been installed or qualified in this phase. Where OEM access is unavailable, use the separately commissioned permanent retrofit pathway.
