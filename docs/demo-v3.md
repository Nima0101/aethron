# Reproduce the perception visuals
The README GIF is an original drawn synthetic scene plus actual temporal CLI outputs. It is not rendered fake detector output: `scripts/temporal_visuals.py` constructs explicit synthetic inputs, runs the real `python -m rescuesense replay` process, and overlays its returned boxes/scores/states. It does not prove pixel detection or hardware.48 frames advance by100ms; GIF playback uses150ms per frame. Daylight, RGB blackout, short occlusion, reacquisition, translation compensation and total loss are included. All-support loss becomes UNKNOWN, then empty UNKNOWN after expiry.

With pinned development requirements installed:

```sh
.venv/bin/python scripts/temporal_visuals.py
.venv/bin/python scripts/temporal_visuals.py --out build/reproduced-visuals
.venv/bin/python scripts/verify_visuals.py build/reproduced-visuals
.venv/bin/python scripts/temporal_evaluate.py --out build/v3-registered
.venv/bin/python scripts/recorded_visual.py
```

`docs/assets/perception.html` displays the exact generated GIF and links its JSONL inputs/outputs. This static historical replay is never a live safety display. PNG/GIF/JSON/HTML artifacts reproduce byte for byte with the pinned Pillow version. The actual CLI tests also verify malformed replay exits with UNKNOWN and never echoes the bad input.

The recorded failure GIF uses real licensed AOT pixels plus actual detector/registration/tracker output; all false proposals remain visible. [Data rights](../data/aot/README.md). The RGB smoke image is generated by actual pinned YOLOX inference and temporal schema/replay, with only class boxes and no identity analysis. Reproduce it using the optional model commands in the README. [Photo rights](../data/rgb-smoke/README.md).

Browser execution remains blocked on the current local sandbox by the previously recorded Chromium MachPort bootstrap denial. Prepared browser tests do not prove a hosted run. These PNG/GIF artifacts are generated directly by Pillow; no browser screenshot, physical thermal image or live video is claimed. No Visage reference image is redistributed.

Original recording acquisition can also be reproduced from source: `.venv/bin/python scripts/fetch_aot.py` downloads the25 pinned source images, verifies original SHA-256, repeats the declared full-frame resize and compares every byte with the bundled PGM excerpt. This is a network-dependent provenance check; the ordinary recorded E2E remains offline against the frozen pixels.

Freshness displayed on recorded/synthetic captures is replay-clock age, not model inference latency or current physical-world freshness. CPU inference timings are reported separately in the model evidence.
