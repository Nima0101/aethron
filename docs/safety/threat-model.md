# Misuse and threat model v1
Assets: people near sensors, observations, controller safety, evidence integrity. Trust boundaries: physical environment -> sensor/firmware -> bounded local adapter -> validator -> fusion -> public coarse output -> separate controller. Host and authorized adapter can lie; schema validation cannot authenticate physical truth. Compromised OS, malicious forks and repeated external recording cannot be structurally prevented by an open-source library. Never claim misuse-proof.
Threats: spoofed presence, adversarial heat, darkness, occlusion, radar multipath, stale/replayed calibration, clock jumps, payload nesting/size attacks, numeric non-finites, duplicate JSON keys, model substitution, conflicting sensors, person identifiers in metadata, excessive precision, output accumulation, unsafe action assumptions, falsified hardware evidence.
Controls: closed schemas and enums; bounded byte/record/depth counts; no arbitrary metadata; no history/logging/network; coarse quantization; explicit freshness/calibration/quality; disagreement UNKNOWN; finite work; hash-bound declarative model; no executable model loading; fixed controller contracts and expiry. Residual: coarse occupancy can still reveal activity when collected externally. Deployment requires authorization, visible notice, access control outside the core and independent privacy/safety review. No unattended rescue/vehicle/drone actuation is established.
