# Protocol v3 — frozen before implementation
v1/v2 continue unchanged. v3 accepts strict bounded JSON bytes: at most 65536 bytes, depth 8, no duplicate/unknown fields, nonfinite numbers or boolean numbers. Version 3 root fields: version, at_ms, lighting, evidence, mode, contract, scene_break, sensors, ego. Monotonic integer milliseconds (0..2^53-1000); processing receives a separate trusted now_ms. Frame times strictly increase. Evidence is synthetic or recorded or external_unverified; never self-certifies live hardware. mode must be direct; authorized through_obstruction uses coarse v2, outside this tracker. contract is warn/vehicle_stop/drone_hover/drone_land/drone_retreat. lighting daylight/low_light/near_dark/zero_visible; scene_break boolean clears all linkage.

At most five unique sensors: rgb/lwir/radar/depth/nir. Each has exactly kind, at_ms, quality, calibration_until_ms, registered, detections. Quality valid/dark/saturated/occluded/noisy/multipath/dropped/model_error; registered boolean. At most 64 detections in total. Detection fields: class, box, score, variance, range_m. Classes person/cyclist/vehicle/uav/animal/obstacle/equipment/hot/cold/fire_like/smoke. box is normalized x,y,w,h in [0,1], positive extent, inside the image; score [0,1], variance [0.000001,1] in normalized image units squared. range_m null or (0,500] from depth/radar only. All geometry is already registered to the same ordinary visible sensor plane; no raw radar samples, embeddings, external IDs or precise hidden-person outputs.

Timing: frame age <=100ms; sensor age <=100ms, never future relative to frame/now; inter-support skew <=50ms; unexpired calibration required. RGB is eligible only in daylight (conservative); valid LWIR/radar/depth/NIR may continue in zero visible light. Registration false suppresses localization. Invalid sensor reasons remain visible. No valid observation means UNKNOWN, not absence/free-space.

Ego: exactly dx,dy,variance,valid; normalized displacement from previous to current image, each [-0.25,0.25], variance [0,0.05], boolean validity. Robust background estimator requires >=6 displacement samples, >=60% inliers within 0.01 and spread evidence from adapter; it is translation-only. Invalid ego permits current boxes but no valid velocity or future path, and clears prior temporal linkage to avoid false compensation. Camera compensation shifts predicted position and adds variance, never physical velocity.

Maximum 32 tracks. Match geometry by class, centroid distance <=0.2 and Kalman innovation squared/variance <=25. Assignment cost distance/0.2 +0.4*(1-IoU), unmatched cost1.5; assignments with competing costs within0.05 are ambiguous and must not confidently join objects. Fuse only mutually unique same-class cross-sensor boxes with IoU>=0.5; do not fuse two objects from one sensor. Birth score>=0.6, existing continuation>=0.35; two observed updates confirm. Confidence never increases from prediction. Prediction horizon200ms. Miss window<=500ms; any expired measurement/calibration removes supporting provenance immediately; a retained prediction is UNKNOWN/coasting, never observed. Session resets at30s; any track rotates after10s regardless of class; no historical trajectory. Gaps>1s reset linkage. Exits beyond image expire. Max frame delta used by filter1s.

Kalman independent x/y [position, velocity], initial positional variance from detection and velocity variance0.25, acceleration noise0.01, measurement variance provided by adapter. Output current detection box when observed (filter guides association/motion), estimated box only when coasting. Public track includes ephemeral ID, class, box, observed/tentative/coasting state, evidence status, score, covariance, freshness, expires_at_ms, current sources, optional range, normalized compensated velocity/direction and 200ms predicted centre explicitly labelled prediction. No metres/second from image-plane data. Global state PRESENT only with current evidence, otherwise UNKNOWN; all outputs include a contract-bounded defensive recommendation, never SAFE or direct actuation.

Session reset and close erase tracks. Live tokens from system randomness; no caller ID. Deterministic replay is separate, disallows external_unverified, limits 300frames and30s, clears on completion and exports local ordinal IDs only. Replay files may be stored for licensed non-identifying evaluation; no live recording API. Malformed step clears state before returning a fixed error/UNKNOWN, never echoing input. Watchdog removes stale state and emits UNKNOWN even with no incoming frame.
