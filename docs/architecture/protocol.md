# RescueSense protocol 1 — frozen specification
Python 3.9+ standard-library core, CLI and Python API. Runtime has zero third-party packages, no network, persistent history, raw camera/radar interface or actuator API. All API evaluation enters through validated JSON bytes, even in-process adapters.

Input: a single JSON object, maximum 65536 bytes, nesting 8, at most 28 observations. Exact fields: version=1, now_ms integer 0..2^53-1000, clock=monotonic, lighting=daylight/low_light/near_dark/zero_visible, evidence=synthetic/external_unverified, authorized_obstruction boolean, contract=warn/vehicle_stop/drone_hover/drone_land/drone_retreat, zones unique subset of near/sector_a/sector_b/sector_c (1..4), observations list. External observations never become verified-live.
Each observation has exactly sensor, zone, at_ms, calibration_until_ms, quality, values, inference_ms, nonhuman, rect. Sensors: rgb/thermal/thermal_aux/depth_active/depth_passive/depth_aux/radar. Unique (sensor,zone). Quality: valid/dark/saturated/occluded/noisy/multipath/dropped/model_error. All timestamp fields bounded integers; inference_ms 0..100000. Nonhuman boolean. Rect null or four integer normalized grid coordinates [x,y,width,height], 0..100, positive dimensions, within grid; only thermal/depth sensors with nonhuman=true and zone=near can accept rect. Quantization is 1%; no object handle. Radar only in sector zones with authorized_obstruction=true; no direct-view geometry behind barriers. RGB only near and nonhuman=false, rect=null. Values list length 0..256, finite numbers only; invalid inputs reject entirely. RGB/radar require exactly one 0..1 cue; thermal -100..1000 Celsius; depth 0..100 metres. Empty thermal/depth means unavailable. Numbers cannot be bool. JSON duplicate/unknown keys, NaN/Infinity, strings in numeric slots, oversized integers and unsupported enums reject; errors are fixed codes without input echoes.

Eligibility: observation time <= now, age <=500ms, calibration covers now and is no earlier than observation, valid quality, nonempty values, inference_ms<=100. RGB/passive depth withdraw unless daylight. Depth values zero mean invalid whole observation. Calibration is a caller assertion; not proof of physical calibration. Cue scores 0.2..0.8 exclusive are UNKNOWN; <=0.2 ABSENT, >=0.8 PRESENT. Rule thermal: max>=150 fire_like; else max>=60 hot; else min<=0 cold; else ABSENT. Depth: min<=2 obstacle PRESENT else ABSENT. Rule confidence score is 0.9, not probability. Scores publish buckets low/medium/high/unavailable; positive input cue confidence >=0.9 high else medium; absence uses 1-score. No learned human detector shipped.

Output: version, evidence, lighting, degraded, claims, recommendation, valid_until_ms. Four capabilities (human_presence, occupancy_zone, thermal_source, obstacle) for each requested zone. Missing capability -> UNKNOWN. RGB produces human_presence and near occupancy; radar produces sector occupancy only. Thermal cannot identify humans. Each claim: capability, zone, state PRESENT/ABSENT/UNKNOWN, kind human/presence/hot/cold/fire_like/obstacle/none, confidence bucket, confidence_semantics=uncalibrated_score, reasons sorted fixed codes, sources sorted sensor enums, rect null or validated rectangle, valid_until_ms. No source timestamps or exact scores exported. Opposed states or thermal classes -> UNKNOWN/disagreement; eligible timestamps spanning >100ms -> UNKNOWN/skew. Use minimum contributor confidence, never independence multiplication. Invalid inputs contribute reasons and degradation; valid independent contributors may survive. Rectangles require agreement of ALL eligible contributors' rectangles and nonhuman flags; otherwise suppress localization without erasing coarse hazard. UNKNOWN/ABSENT have no rectangle. Output expiry is min(now+200, contributing at+500, calibration expiry). Overall expiry <= each claim expiry. Degraded if any claim UNKNOWN or invalid contributing sensor. No output is SAFE.

Actions: never execute. warn->WARN. Contracts vehicle_stop/drone_hover/drone_land/drone_retreat map to STOP/HOVER/LAND/RETREAT on any PRESENT or UNKNOWN, else WARN. These are explicit integration fixture contracts, not proof that landing/retreat is physically safe. Recommendation includes contract, action, reason=hazard_or_unknown/observe, requires_independent_controller=true. Renderer recomputes from bounded input and supplied time, or expires verified output before drawing. CLI evaluate accepts now from request for deterministic replay; integrators must supply trusted monotonic time and run a watchdog. No freshness claim against wall time. No stable state between calls; input forgery/replay within caller-supplied time cannot be detected.
