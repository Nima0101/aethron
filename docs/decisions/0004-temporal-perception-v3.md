# ADR 0004 — bounded temporal perception (accepted, 2026-10-08)
Authority: owner capability amendment v3. This supersedes only older bans on temporary tracking and local motion state; the v2 human-box amendment remains in force. Earlier constitutions and freeze hashes are preserved. This ADR extends engineering, safety, privacy and misuse models, capability matrix and verification; historical documents are not silently edited.

Keep Python's dependency-free safety core and v1/v2 interfaces. Add explicit v3 schema, calibration/fusion, geometry/assignment, state estimation, session lifecycle and replay boundaries. A conventional constant-velocity Kalman filter plus globally optimal geometric assignment is small enough to audit and handles non-overlapping small detections. L2 plus IoU is inspired by published FLIT/SORT mechanisms, independently implemented, not copied from GPL SORT. Compare against greedy IoU without motion. ByteTrack's low-score continuation is allowed only on existing tracks; it must not create a low-confidence object. OC-SORT is a credible nonlinear alternative, but extra trajectory history and complexity are not justified before the simpler measured baseline. No appearance model.

Translation-only camera compensation is deliberate: robust median background displacement with outlier rejection, or calibrated adapter-provided displacement. It does not claim rotation/parallax/world-motion recovery. Invalid compensation withdraws velocity/prediction validity; no camera motion is silently assigned to an object's physical motion. Range comes only from registered depth/radar, never monocular box size. Pixel-plane velocity is not metres/second.

Fusion requires valid timing, calibration and registration and uniquely overlapping same-class observations. Correlation is unknown: confidence is the minimum supporting score, variance the maximum; no invented independent-sensor confidence gain. Semantic detector scores are uncalibrated. A thermal intensity blob cannot become a person or drone by temperature alone.

Runtime has no persistence/network/model-download/actuation path. A caller is a trust boundary: schema cannot prove sensor calibration or stop a malicious downstream logger. Deployment access control, consent and independent safety controller are required; no claim that open-source code prevents all misuse. Sensor scene change must clear state. Hard lifetime rotation also bounds damage from a caller that omits scene boundaries. Replay IDs are canonical local ordinals in an explicitly recorded/synthetic-only API; live session tokens are random and never supplied by input.

Loss or malformed data produces an explicit UNKNOWN/defensive outcome. Stale state is removed before association; no re-identification store. Per-frame snapshots expire, and the caller must invoke the watchdog when acquisition stops. Returned snapshots cannot be revoked from an external consumer: expire them independently. No persistent live-human logs, raw exports or trajectory buffers are supplied.

Publication and production gates remain cumulative. Recorded data may close a software replay test but never device, thermal, semantic-class or controller qualification. Benchmark failures remain failures. Local evidence cannot stand in for hosted CI.
