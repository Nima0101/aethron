# ADR 0006 — optional pinned RGB model integration
2026-10-08, before model execution. The original grayscale proposal baseline remains unchanged and its failed aircraft evaluation remains public. Add an independently wired OpenCV Zoo YOLOX-S ONNX adapter for ordinary RGB person/vehicle/animal/obstacle perception. This is model integration, not a thermal/UAV model or accuracy qualification.

Sources: [official model directory](https://github.com/opencv/opencv_zoo/tree/main/models/object_detection_yolox), [model-specific Apache2 license](https://github.com/opencv/opencv_zoo/blob/main/models/object_detection_yolox/LICENSE), [OpenCV DNN](https://docs.opencv.org/4.x/d6/d0f/group__dnn.html). The official LFS pointer supplies SHA-256 c5c2d13e59ae883e6af3b45daea64af4833a4951c92d116ec270d9ddbe998063 and size35,858,002 bytes. Only those exact bytes may load; reject tamper before native parsing. No arbitrary user model/plugin loading. Downloader is a separate explicit development script; runtime never downloads. Preserve the model-specific license and provenance. Upstream reports COCO training/evaluation, not thermal/night or rescue qualification; no training by AETHRON and no inherited accuracy claim.

Frozen adapter: uint8 RGB max1280×720, resize preserving aspect to640 square, padding114, channel-first float32 with no normalization, YOLOX strides8/16/32 decode, score objectness×class, score threshold0.35, per-class NMS IoU0.5, top32. Map person0; vehicles2/3/5/6/7/8; animals14..23; bicycle1 to equipment (not inferred rider); aircraft4 and street objects9..13 to obstacle. All other classes discarded. Never map airplane to UAV or heat to person. Range null. Variance0.0001 is an uncalibrated adapter parameter, not measured error. Reject nonfinite/invalid output. Darkness suppresses RGB before inference; LWIR still uses a separately qualified semantic adapter. No face crops/embeddings/history/raw export. Adapter holds network weights only, not prior images.

Use optional pinned OpenCV4.13.0.92 and NumPy2.3.5, separately inventoried/audited; core remains stdlib. Record actual model load/inference on all25 frozen AOT frames, empty-image negative, hash tamper, zero-light suppression and class-map exclusions. Compare deterministic detections across two executions; report FP/FN and wall latency without tuning. This known excerpt is an integration/regression set, not unseen validation for this new hypothesis. CPU inference has no hard deadline guarantee; deployment must put inference behind an independently timed worker/watchdog and pass current monotonic timing into the safety core. If latency exceeds sensor freshness, live evidence is ineligible. No physical/platform-ready claim follows from an offline run.
