# ADR 0001: bounded portable observation runtime
Accepted after primary-source research and darkness update. Choose Python standard library for transparent portable reference semantics and straightforward audits. This is not a hard-real-time runtime. Ship thermal/depth rule extraction, coarse minimized camera/radar adapters, fusion and recommendation fixtures. No generic detector runtime, external executable plugin or autonomous motion. Pure evaluations isolate privacy and make permutation/reference checks feasible. SVG visualization uses rectangles only after non-human exclusion evidence; ambiguous thermal regions stay coarse. Hardware acquisition/native mobile bindings and empirical human detection remain blocked by concrete device/model/data validation requirements, not hidden implementations.
