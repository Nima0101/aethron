# ADR 0005 — bounded background translation adapter
2026-10-08, additive before registration evaluation. Protocol v3's supplied ego displacement remains available. Add an original grayscale block matcher so recorded pixels can supply measured translation rather than assuming a stationary camera. This is not full visual odometry.

Fixed method: decimate image by4; 6×4 distributed interior centres; each7×7 patch must have intensity variance>=25; search displacement ±4 decimated pixels with mean absolute difference; accept best error<=20 and second best minus best>=0.5. Require >=6 accepted distributed samples before the frozen median estimator (60% inliers within normalized0.01). Duplicate low-texture optima are invalid, not zero motion. Exclude image borders from full search. Input resolution cannot change mid-pair. No object labels or appearance embeddings enter this estimator. Keep one previous frame only in offline recorded reproduction; runtime adapter itself is stateless. Synthetic tests independently shift a textured background, include moving foreground/outliers, flat-image and shape-change negatives. Report the earlier unregistered recorded result as a retained baseline and do not change detector thresholds or metric gates.

Limited translation model fails under rotation, parallax, repetitive texture and large displacement. No metric/world velocity claim. Unvalidated transforms must clear linkage and suppress motion output. This additional algorithm is frozen before its first evaluation; it cannot upgrade physical sensor qualification.
