# v3 model/data provenance and model card
The stdlib core uses an original constant-velocity model, geometric assignment and explicit confidence/expiry rules. No appearance embeddings or learned re-identification components. Parameters were frozen before evaluation. Confidence scores and variances are uncalibrated and must not be advertised as empirical probability/error bounds.

The original grayscale local-contrast detector has no training. Its fixed parameters are in the frozen v3 verification matrix. It outputs obstacle proposals only. On the AOT excerpt it fails to identify the tiny aircraft; do not deploy it as an airborne detector.

Optional RGB model: OpenCV Zoo `object_detection_yolox_2022nov.onnx`, YOLOX-S,35,858,002 bytes, SHA-256 `c5c2d13e59ae883e6af3b45daea64af4833a4951c92d116ec270d9ddbe998063`. [Official model and model-specific license](https://github.com/opencv/opencv_zoo/tree/main/models/object_detection_yolox), [preserved Apache2 license](YOLOX-LICENSE.txt), [frozen integration policy](../decisions/0006-pinned-rgb-detector.md). We independently implement the adapter according to the documented tensor layout/decode. Attribution: OpenCV Zoo and the YOLOX authors. No upstream code, imagery, scores or endorsements are presented as our results.

Upstream describes COCO training and evaluation. AETHRON did not train or fine-tune these weights, and has not independently audited every training image's rights or representation. Model-directory Apache2 terms permit the selected artifact; that is not a guarantee of training-data provenance or privacy. Common smoke images may overlap training and cannot substantiate generalization. AOT is an integration/regression excerpt, not a representative field validation set. Do not claim thermal/night/UAV performance from RGB weights.

Acquisition: explicit hash-checked development downloader; runtime accepts only the exact pinned model bytes and parses no arbitrary ONNX/custom plugin. CPU OpenCV4.13.0.92 / NumPy2.3.5 are optional, pinned and audited separately; the Python3.9+ core remains independent. Model assets stay outside the source/wheel/zipapp; source provenance records the expected hash and the user reproduces acquisition explicitly. No mutable download is accepted on hash mismatch.

Input: RGB uint8, bounded dimensions. Output: permitted class, normalized rectangle, uncalibrated score/variance, no identity, no raw imagery, no history. Aircraft maps to obstacle; bicycle alone does not establish a cyclist. Thermal/fire/UAV/cyclist classes require a separately validated semantic adapter. Radar/depth range is not inferred by the RGB model.

Native inference is synchronous and is not a deadline-guaranteed safety component. Isolate it behind a timed worker and independent safety watchdog in a real integration. Native buffers may retain intermediate pixels; resetting the input is not certified secure erasure. There is no deliberate frame archive, export API or network path. Physical devices, face/name analysis, profiling and pursuit are absent.

Every data source is attributed separately: [AOT excerpt](../../data/aot/README.md), [RGB smoke photos](../../data/rgb-smoke/README.md), original synthetic sequences. Freeze manifests detect modified fixtures; no evaluation image enters a training process. Redistribution includes the data license and modification description. Public visuals are outputs of actual executions and explicitly labeled synthetic, recorded or still-photo tests.
